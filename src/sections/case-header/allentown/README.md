# Case Header Allentown

Structural implementation for the [Case Template](https://www.figma.com/design/7rHrxb3twyBvPo9QxkOBly/KSW-1-Tulip-Tech-Website?node-id=5639-524475&t=OtYEVTRRdAJJYQ0v-11), frame **261014 | Tulip - Europe - Desktop - Case Template**.

- Composes the shared Intro and Content Hero Media contracts.
- Customer logo is optional.
- Hero media selects exactly one image, S3-uploaded video, or supported external video URL. Video requires a poster.
- Breadcrumb is route-derived. It is not editable section content.

The current files are generated structural scaffolding. Video provider validation and playback markup require the paired implementation pass.
