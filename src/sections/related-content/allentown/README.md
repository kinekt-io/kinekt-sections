# Related Content Allentown

Structural implementation for the [Case Template](https://www.figma.com/design/7rHrxb3twyBvPo9QxkOBly/KSW-1-Tulip-Tech-Website?node-id=5639-524475&t=OtYEVTRRdAJJYQ0v-11) and [Article Template](https://www.figma.com/design/7rHrxb3twyBvPo9QxkOBly/KSW-1-Tulip-Tech-Website?node-id=5639-526183&t=OtYEVTRRdAJJYQ0v-11).

- Editor selects one or more published content documents explicitly.
- The later adapter resolves each document's type, title, card excerpt, route, and hero image or video poster.
- The design is an equal-card related-posts grid, not the existing Featured Insights featured/recent arrangement.
- The overview CTA is independently optional and uses the shared Content-or-URL Button contract.
