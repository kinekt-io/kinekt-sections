# Project Glance Allentown

Structural implementation for the [Case Template](https://www.figma.com/design/7rHrxb3twyBvPo9QxkOBly/KSW-1-Tulip-Tech-Website?node-id=5639-524475&t=OtYEVTRRdAJJYQ0v-11), frame **261014 | Tulip - Europe - Desktop - Case Template**.

- Renders a heading and repeatable `Key Fact Allentown` items.
- Facts are an unordered list because their visual order conveys no sequence.
- Desktop grid and mobile stacking remain renderer-owned.

The current files establish the Payload, Astro, type and preview entrypoints; the approved visual layout is a later component-specific implementation pass.
